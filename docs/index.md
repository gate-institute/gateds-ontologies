# GATE Institute Ontologies and Profiles

This repository contains ontologies, vocabularies, and semantic profiles developed at the GATE Institute, Sofia University.

## GATE Data Spaces (GDS) ODRL Profile

The GDS ODRL Profile extends the W3C Open Digital Rights Language (ODRL) with concepts for expressing policies in data-space environments.

**Current version:** 0.1.0
